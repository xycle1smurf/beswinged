Erste Schritte

  • Log öffnen: Datei → Log öffnen… (Strg+O), Datei → Zuletzt geöffnet oder die Datei ins Fenster ziehen.
  • Schema laden: Schema → Schema laden… (Strg+L) oder eine .yaml/.properties-Datei ins Fenster ziehen. Ohne Schema werden die Spalten aus den Feldern der ersten 200 Zeilen erkannt.
  • Ein Klick auf eine Zeile zeigt unten die Detailansicht: Klick auf # zeigt die ganze Zeile als formatiertes JSON, Klick auf eine andere Zelle nur deren Wert mit echten Zeilenumbrüchen.
  • Log einfügen: Datei → Log einfügen… (Strg+Umschalt+V) öffnet ein Textfeld mit dem Inhalt der Zwischenablage, z.B. einem Log-Ausschnitt aus Teams. Anzeigen (Strg+Enter) zeigt ihn wie eine Datei. Reparieren fügt umbrochene JSON-Objekte zusammen und korrigiert Zeichen, die beim Kopieren entstehen (geschützte Leerzeichen, „typografische“ Anführungszeichen).
  • Kommandozeile: beswinged app.log --schema schema.yaml [--ram|--seek] [--tail]

Große Dateien

Beim Öffnen wählen Sie, wie geladen wird (ab 1 GB ist Seek vorausgewählt):

  • In den RAM laden: am schnellsten, braucht aber etwa so viel Speicher wie die Datei groß ist.
  • Datei-Index (Seek): Im Speicher bleiben nur die Zeilenanfänge und jeder 20. Zeitstempel; angezeigte Zeilen werden gezielt aus der Datei gelesen.

Datei → Datei-Index (Seek) schaltet nachträglich um. Filter und ausgewählte Zeile bleiben erhalten. Die Tabelle ist schon während des Einlesens bedienbar.

Spalten & Schema

  • Spalten per Drag & Drop umsortieren, Breite ziehen. Rechtsklick auf den Spaltenkopf: Ausblenden, Zeitzone (Zeitstempel), Package original / compact / Class only (Klassennamen), Auswahlfilter, Spaltentyp Loglevel.
  • Ansicht blendet Spalten ein und aus und stellt die Zeitzone ein. Lokal berücksichtigt Sommer- und Winterzeit.
  • Änderungen werden automatisch in die geladene Schema-Datei zurückgeschrieben. Das automatisch erkannte Schema lässt sich mit Schema → Schema speichern unter… (Strg+S) ablegen.
  • Das Menü Schema zeigt die 20 zuletzt geöffneten Schemas.

Filter

Alle Filter wirken gemeinsam (UND). Zurücksetzen leert alle.

  • Textfilter (Strg+F): Teilstring ohne Beachtung der Groß-/Kleinschreibung oder Regex, auf die ganze Zeile oder eine Spalte. Nicht kehrt den Filter um.
  • Auswahlfilter: Dropdown mit allen Werten einer Spalte. Tippen sucht, Enter, Leertaste oder Klick wählt an und ab. Bei Paketnamen gibt es zusätzlich Einträge wie org.example.*, die alle Werte darunter treffen.
  • Loglevel: „≥ WARN“ zeigt WARN, ERROR und FATAL (Log4j, Logback und JUL).
  • Gespeicherte Filter: Filter → Speichern als… legt alle aktuellen Filter unter einem Namen ab; darunter stehen die gespeicherten Filter zum Anwenden.

Zeitraum

  • Dritte Filterzeile: Von und Bis über den Kalender (Symbol im Feld) oder getippt, z.B. 2026-11-19 08:15:30, 19.11.2026 08:15, 08:15 oder 2026-11-19T07:15:00Z. Ein leeres Feld lässt die Seite offen.
  • Zusätzlich davor/danach zeigt n Zeilen vor bzw. nach dem Zeitraum, unabhängig von ihrer Zeit.
  • Rechtsklick → Umliegender Zeitraum… übernimmt die Zeit der Zeile und füllt Von/Bis (1 Min bis 12 h; umliegend, nur davor oder nur danach).
  • Gehe zu Von springt zur ersten Zeile ab Von, ohne zu filtern.

Tabelle & Kopieren

Rechtsklick in der Tabelle:

  • Kopiere Zelle: der Wert wie in der Detailansicht.
  • Kopiere als Markdown: die ausgewählten Zeilen strukturiert für Dokumentationen, mehrzeilige Werte (Stacktraces, JSON) als Codeblock.
  • Rohzeile(n) oder Zellen (Tab-getrennt) kopieren.

Highlight Filter (rechts über der Detailansicht): Regex, Groß-/Kleinschreibung egal. Alle Treffer im Text darunter werden gelb markiert. Enter bzw. Umschalt+Enter springt zum nächsten bzw. vorherigen Treffer, Esc leert das Feld. Der Filter bleibt beim Wechsel der Zeile aktiv und blendet nichts aus.

Ungültige JSON-Zeilen sind lila hinterlegt. Die Zeilennummer # zählt nur nicht-leere Zeilen.

Tail

Datei → Tail / Schreiben folgen (Strg+T) liest neue Zeilen alle 0,5 s nach. Aktive Filter werden fortgeschrieben; steht die Ansicht am Ende, scrollt sie mit.

Mehrere Dateien

  • Das Menü Fenster listet alle geöffneten Dateien; Strg+1 bis Strg+9 wechselt. Jede Datei behält Schema, Filter, Zeitraum und Auswahl.
  • Datei → Schließen (Strg+W) schließt die angezeigte Datei; danach wird die Datei davor angezeigt.
  • Beim nächsten Start sind alle Dateien wieder da.

Kubernetes / OpenShift

  • Extras → Connect Settings…: Cluster anlegen (Werkzeug kubectl oder oc, kubeconfig, Kontext, Standard-Namespace). Aus kubeconfig importieren legt je Kontext einen Eintrag an, Verbindung testen prüft den Zugriff. Passwörter und Tokens speichert beswinged nicht: Angemeldet wird wie gewohnt, z.B. mit oc login.
  • Extras → Connect… (Strg+K): Cluster, Namespace, Art (Pod oder Deployment, ReplicaSet, StatefulSet, DaemonSet, DeploymentConfig) und Name wählen; Laden listet die vorhandenen mit Status. Bei Workloads werden alle Pods gelesen.
  • Seit, Letzte Zeilen und Vorheriger Container begrenzen das Log. Mit Folgen kommen neue Zeilen laufend hinzu (Tail); Datei → Schließen beendet die Verbindung.
  • Extras → Show Namespace…: eigenes Fenster mit allen Objekten eines Namespaces als Kacheln, ähnlich Argo CD. Kinder (ReplicaSet, Pod, Job, Endpoints) stehen rechts neben ihrem Besitzer. Symbole: grünes Herz = Healthy, blauer Kreis = Progressing, rotes gebrochenes Herz = Degraded, Pause = Suspended. Filter nach Name, Zustand und Art; Strg+Mausrad zoomt, Ziehen verschiebt, Auto lädt alle 10 s neu.
  • Doppelklick auf eine Kachel öffnet ein eigenes Fenster mit Manifest (YAML, Suche mit Strg+F), Zusammenfassung und Events. Es können beliebig viele offen sein. Werte von Secrets sind verdeckt, bis Werte anzeigen gewählt wird. Rechtsklick → Logs… öffnet Connect mit dem Objekt.

Einstellungen

  • Ansicht → Einstellungen…: Darstellung der Zeilen je Loglevel (fett, kursiv, Farbe).
  • Alle Einstellungen, Schema-Kopien und gespeicherten Filter liegen im Ordner .beswinged im Benutzerverzeichnis.

Grenzen

  • Kein Sortieren; die Reihenfolge entspricht der Datei.
  • Zeitraum und Zeitsuche setzen zeitlich sortierte Zeilen voraus.
  • Nach einer Log-Rotation die neue Datei öffnen.
  • Zeilen werden ab 64 MB, Zelltexte ab 2.000 Zeichen abgeschnitten.
